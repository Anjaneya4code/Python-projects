# YouTube Video Downloader

A simple terminal-based Python application that downloads YouTube videos using the `yt-dlp` library.

## Features
- Download YouTube videos from a URL
- Saves the video in MP4 format
- Simple terminal interface
- Error handling

## Technologies
- Python
- yt-dlp
- FFmpeg

## Installation

```bash
pip install yt-dlp
```

FFmpeg is required for merging video and audio streams.

## Run

```bash
python youtube_downloader.py
```

Enter the YouTube video URL when prompted.

**Note:** Download only content you have permission to download and follow the platform's terms.
