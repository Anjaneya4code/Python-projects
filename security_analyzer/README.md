# 🔐 Password Security Analyzer

A Streamlit-based Python application that analyzes password strength and provides an estimated time required for a hypothetical high-speed offline guessing attack.

## Features

- Password strength analysis
- Password length detection
- Entropy calculation
- Estimated guessing time
- Character-type analysis
- Security recommendations
- Interactive Streamlit interface

## Technologies

- Python
- Streamlit
- Math
- String

## Installation

```bash
pip install streamlit
```

## Run

```bash
streamlit run app.py
```

## Note

The crack-time result is only an estimate based on an assumed guessing rate. Real-world attack times vary depending on hashing methods, hardware, attack techniques, and password patterns.
