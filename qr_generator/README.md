# QR Code Generator

A simple Python application that generates QR codes from text or URLs using the `qrcode` library and provides a basic graphical interface using Tkinter.

## Features
- Enter text or URL
- Generate QR code
- Save QR code as PNG
- Simple Tkinter GUI

## Technologies
- Python
- Tkinter
- qrcode
- Pillow

## Installation

```bash
pip install qrcode[pil]
```

## Run

```bash
python qr_code_generator.py
```

The generated QR code is saved as `generated_qr.png`.
