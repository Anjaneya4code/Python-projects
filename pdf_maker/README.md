# PDF Maker

A simple Python application that creates PDF files from user-entered text using the `ReportLab` library.

## Features
- Enter PDF file name
- Add a title
- Add text content
- Automatically create a PDF file
- Supports multiple lines of text

## Technologies
- Python
- ReportLab

## Installation

```bash
pip install reportlab
```

## Run

```bash
python pdf_maker.py
```

Enter the file name, title, and content when prompted.

## Output

The generated PDF is saved in the same folder as the Python program.
